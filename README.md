# Life & Performance

Planificateur sport, nutrition et quotidien, dans un seul fichier `index.html`.

Les données sont enregistrées dans le navigateur de chaque appareil, et synchronisées entre appareils une fois connecté (bouton en haut à droite, e-mail + mot de passe). La synchronisation passe par Firebase (projet `dany-ipos`).

Le bouton « Sauvegarde » permet toujours d'exporter ou d'importer une copie des données.
